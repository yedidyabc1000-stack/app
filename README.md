# נגן — נגן מוזיקה למכשירי מקשים

נגן מוזיקה מקומי, בעברית, עם ממשק כהה ופשוט שמותאם למכשירי Android עם מקשי ניווט פיזיים.

## מה יש באפליקציה
- סריקה אוטומטית של ספריית המוזיקה במכשיר.
- הצגת שם השיר, האמן, האלבום ומשך הנגינה.
- הפעלה, השהיה, שיר קודם ושיר הבא.
- ניווט בעזרת החצים ומקש OK / Enter.
- תמיכה במקשי המדיה הפיזיים (Play/Pause, Next, Previous).
- ממשק RTL בעברית, ללא צורך במסך מגע.
- תאימות החל מ-Android 4.4 (API 19).

## בנייה
נדרשים JDK 17, Android SDK 35 ו-Gradle 8.7.

```bash
gradle :app:assembleDebug
```

קובץ ה-APK ייווצר ב:
`app/build/outputs/apk/debug/app-debug.apk`

## הרשאות
האפליקציה מבקשת הרשאת קריאת אחסון כדי לסרוק את קובצי המוזיקה. ב-Android 4.4 ההרשאה ניתנת בזמן ההתקנה; בגרסאות חדשות יותר היא מתבקשת בעת ההפעלה הראשונה.

## הורדה
GitHub Actions בונה APK בכל דחיפה לענף `main` ושומר אותו כ-artifact. הבנייה הראשונה גם מפרסמת Release עם קובץ APK.
