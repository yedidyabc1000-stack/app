# נגן — גרסת Android 4.4

נגן מוזיקה למסכים קטנים ולניווט במקשים, ללא ספריות חיצוניות.

## דרישות
- Android 4.4 (API 19) ומעלה
- הרשאת קריאה של קובצי מדיה

## תכונות בגרסה 2.1.0
- שירים, אמנים, אלבומים, פלייליסטים ולשונית "מתנגן עכשיו"
- יצירת פלייליסטים מקומיים וייבוא קובצי M3U/PLS
- לחיצה ארוכה על שיר: נגינה אחרי השיר הנוכחי או הוספה לפלייליסט
- סינון קבצים מוסתרים, תיקיות מוסתרות ותיקיות עם ‎.nomedia
- מעקב MediaStore וסריקה אוטומטית ברקע לאחר שינוי בספריית המדיה
- רשימת "המושמעים ביותר", בחירת אלבומים לאמן ופיצול שמות אמנים לפי X
- רשימות עם כתב מוגדל ומסך נגן אנכי עם עטיפה גדולה, פינות מעוגלות ופס התקדמות מותאם
- ניווט במקשי חיצים, אישור, חזרה ומקשי מדיה
- בנייה ואריזת APK ו-ZIP מתבצעות ב-GitHub Actions עם כל עדכון לענף `android44-rebuild`

## בנייה
נדרש JDK 17, Gradle 8.7 ו-Android SDK Platform 35. מתוך תיקיית הפרויקט:

```bash
gradle --no-daemon :app:assembleDebug
```
