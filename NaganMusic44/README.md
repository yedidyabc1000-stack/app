# נגן — גרסת Android 4.4

נגן מוזיקה חדש בסגנון הממשק של ה-APK שסופק, עם התאמה למסכים קטנים ולניווט באמצעות מקשי חומרה.

## דרישות
- Android 4.4 (API 19) ומעלה
- הרשאת קריאה של קובצי מוזיקה

## תכונות
- שירים, אמנים, אלבומים ופלייליסטים
- מסך "מתנגן כעת" עם תמונת עטיפה מלאה וללא חיתוך, ביחס הממדים המקורי ובפינות מעוגלות קלות
- פלייליסט "המושמעים ביותר" שנבנה ממספר ההשמעות שנשמר מקומית
- בחירת אמן מציגה אלבומים כשיש לאמן יותר מאלבום אחד
- פיצול שם אמן לפי מפריד עצמאי `X` (למשל `אבי X לוי` יוצר שני שיוכי אמן)
- מקשי חיצים, אישור, חזרה ומקשי מדיה

## בנייה
נדרש JDK 17, Gradle 8.7 ו-Android SDK Platform 35. הפקודה:

```bash
gradle assembleDebug
```

ה-APK יופיע ב-`app/build/outputs/apk/debug/app-debug.apk`.
